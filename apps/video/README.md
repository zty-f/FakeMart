# FakeMart Promo Video

The `FakeMartPromo` composition is a 30-second, 1080x1920 Remotion video.

```bash
pnpm video:dev
pnpm video:render
```

- Composition: `apps/video/src/FakeMartPromo.tsx`
- Narration: `apps/video/voiceover.txt`
- Rendered video: `docs/fakemart-promo-30s.mp4`
- Cover: `docs/fakemart-promo-cover.png`
